function add (   rules,
  which,
  rule 
)

Converts file patterns or regular expressions to nodemon compatible RegExp matching rules.

Note: the rules argument object is modified to include the new rule and new RegExp

Example:

var rules = { watch: [], ignore: [] };
add(rules, 'watch', '*.js');
add(rules, 'ignore', '/public/');
add(rules, 'watch', ':(\d)*\.js'); // note: string based regexp
add(rules, 'watch', /\d*\.js/);
Parameters
{Object}rules containing watch and ignore. Also updated during execution
{String}which must be either "watch" or "ignore"
{String|RegExp}rule the actual rule.
