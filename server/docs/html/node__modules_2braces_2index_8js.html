picomatch

Creates a matcher function from one or more glob patterns.

The returned function takes a string to match as its first argument, and returns true if the string is a match. The returned matcher function also takes a boolean as the second argument that, when true, returns an object with additional information.

const picomatch = require('picomatch');
// picomatch(glob[, options]);
const isMatch = picomatch('*.!(*a)');
console.log(isMatch('a.a')); //=> false
console.log(isMatch('a.b')); //=> true

Processes a brace pattern and returns either an expanded array (if options.expand is true), a highly optimized regex-compatible string.

This method is called by the main braces function.

console.log(braces.create('user-{200..300}/project-{a,b,c}-{1..10}'))

braces expand = require('./lib/expand')

Expands a brace pattern into an array.

This method is called by the main braces function when options.expand is true. Before using this method it's recommended that you read the performance notes) and advantages of using .compile instead.

const braces = require('braces');
console.log(braces.expand('a/{b,c}/d'));
//=> ['a/b/d', 'a/c/d'];
